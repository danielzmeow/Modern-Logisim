# 与经典 Logisim 的功能对照

这份文档按功能域对照 Logisim 2.7.1，并标注本项目的实现状态。  
状态：**已实现** = 可直接使用；**部分** = 有等价能力但不完全一致；**未实现** = 尚未提供。

## 1. 仿真内核

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 组合逻辑迭代到不动点 | 已实现 | 支持反馈电路；64 轮不收敛时标记为 E |
| 多驱动 / 冲突检测 | 已实现 | 相同值可并联；不同强驱动变为 `E`（红色） |
| 高阻态 `Z` | 已实现 | 三态缓冲器、未连接网络；画布虚线显示 |
| 弱驱动 / 上拉下拉 | 已实现 | 无强驱动时由 Pull Resistor 决定电平 |
| 总线 / 多位信号 | 已实现 | 1–32 bit，导线显示位宽与十六进制值 |
| 时钟与边沿触发 | 已实现 | DFF、Register、Counter、RAM 支持上升/下降沿 |
| 时序元件复位 | 已实现 | Register / Counter 带复位端 |
| 传播延迟、精确时序 | 未实现 | 采用每帧收敛的抽象仿真，不建模门延迟 |
| 振荡定位 | 部分 | 不收敛时把相关网络标为 E，但不报告具体环路 |

## 2. 元件库

### 2.1 逻辑门

- 已实现：NOT、AND、OR、NAND、NOR、XOR、XNOR、Buffer、Odd/Even Parity、Controlled Buffer/Inverter。
- 已实现：多输入门（2–5 路）、多位按位运算、门尺寸 30/50/70。
- 未实现：普通门上的三态属性、输入取反小圆圈、Logisim 的 TTL 74xx 库。

### 2.2 连线与基础

- 已实现：输入/输出 Pin、Probe、Tunnel、Clock、Constant、Power、Ground、Pull Resistor、Bit Extender、总线分线/合线。
- 部分：分线/合线采用统一的每路位宽，未实现 Logisim Splitter 的任意 bit 映射。
- 未实现：Logisim 风格的导线颜色属性、探针组合显示。

### 2.3 数据选择

- 已实现：Multiplexer、Decoder、Demultiplexer、Priority Encoder、Bit Selector。
- 部分：选择端位置、部分 enable/三态细节与 Logisim 不完全一致。
- 未实现：Logisim Evolution 的额外端口布局选项。

### 2.4 算术运算

- 已实现：Adder、Subtractor、Multiplier、Comparator、Shifter（左移/逻辑右移/算术右移）。
- 未实现：Negator、Bit Adder、Bit Finder、Logisim Evolution 的 Divider 等。

### 2.5 存储

- 已实现：D Flip-Flop、Register、Counter（上/下计数）、RAM、ROM。
- 已实现：RAM/ROM 内容的十六进制编辑器；RAM 运行时可写。
- 未实现：Shift Register、Random Generator、Memory 的 OE/分页编辑器、RAM 内容写入 `.circ`。
- 部分：RAM/ROM 的 `.circ` 只导出位宽参数，不导出存储内容；项目 JSON 会保存全部电路与已写入的存储内容。

### 2.6 输入/输出

- 已实现：Button、LED、七段数码管、Clock、输入/输出 Pin、Probe。
- 未实现：RGB LED、Hex Digit Display、Joystick、Keyboard、TTY/Terminal、Buzzer。

### 2.7 子电路

- 已实现：多电路项目、子电路实例、自动生成符号引脚、跨层级仿真、递归检测、`.circ` 多电路导入/导出。
- 部分：子电路没有单独的“外观编辑”模式；符号引脚按输入/输出自动左右排列。
- 未实现：Logisim 的 subcircuit appearance 编辑器、按实例覆盖参数。

## 3. 编辑操作

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 选择 / 框选 / 增选 | 已实现 | ⇧ / ⌘ 加选 |
| 拖动、旋转、微移 | 已实现 | R / ⇧R；方向键 10 / 1 单位 |
| 移动时导线跟随 | 已实现 | 拖动、方向键或在检查器改坐标时，连在引脚上的导线自动跟随并保持正交 |
| 撤销 / 重做 | 已实现 | 每个当前电路独立历史栈 |
| 复制选中 | 已实现 | 元件与导线段一起复制 |
| 删除单段导线 | 已实现 | 默认点击只选一段；右键可删除整条网络 |
| 剪断导线段 | 已实现 | 右键“在此处剪断导线” |
| 选择整条网络 | 已实现 | ⌥ 点击或右键菜单 |
| 拖动导线 / 端点编辑 | 未实现 | 可删除、剪断、重画，不能直接拖拽已有导线 |
| 水平/垂直翻转 | 部分 | 通过四边形旋转实现，未提供独立翻转命令 |
| 对齐 / 分布 | 未实现 | |
| 批量属性编辑 | 部分 | 多选仅有旋转/复制/删除 |
| 复制粘贴到其他电路 | 未实现 | 目前复制是原地偏移副本 |

## 4. 分析工具

- 已实现：**真值表**。枚举输入 Pin（支持多位、最多 4096 行），读取输出 Pin / LED / Probe / 七段数码管；显示 `E` / `Z`；时序电路每行从复位状态求值；可复制 CSV。
- 已实现：**从布尔方程生成电路**。支持 `! & ^ |`、括号、常量 0/1，多行 `输出 = 表达式`，自动共享子表达式并生成门级电路。
- 未实现：Logisim 的 Combinational Analysis（从真值表最小化并生成表达式/PLA）。
- 未实现：波形/时序图、仿真日志、覆盖率统计。

## 5. 文件与项目

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 本地自动保存 | 已实现 | localStorage 保存整个多电路项目 |
| 项目 JSON 保存/打开 | 已实现 | 包含全部电路、子电路、RAM/ROM 内容 |
| `.circ` 导入 | 已实现 | 多电路、子电路、Pin/Probe/常见门/触发器/寄存器/计数器/复用器/算术/七段数码管等 |
| `.circ` 导出 | 已实现 | 多电路与子电路；统一平移至正坐标 |
| Splitter 导入/导出 | 未实现 | 自定义分线/合线仍会在导出时跳过 |
| RAM/ROM 内容导出 | 部分 | `.circ` 仅导出参数；项目 JSON 保留 attrs 内容，当前电路 RAM 运行内容在保存快照时捕获 |
| TTL / SoC / 特殊元件 | 未实现 | 导入时跳过并提示 |
| 打印 / 导出图片 | 未实现 | |

## 6. 界面与平台

- 已实现：浅色/深色/跟随系统、Paper/Graphite 画布、中文/英文、命令面板、右键菜单、检查器、快捷键面板、欢迎页、Toast。
- 已实现：macOS 触控板平移/捏合缩放、Retina 渲染。
- 未实现：Logisim 的项目选项（仿真频率、线色、工具栏自定义）、多窗口、全屏演示模式。
